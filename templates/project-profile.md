## Testing boundary
- **`developer` runs:** unit + service + invariant/negative/race tests, build, lint — and marks its own homework.
- **`reviewer` runs nothing.** It reads tests to judge coverage and never claims a result.
- **`qa` executes** the suite, the build, and Playwright specs against the running app. It is the only agent that does. A check it didn't run is reported `not covered`, never `pass`.
- **Human runs + merges:** live-provider, real-credential, second-tenant, and true multi-process concurrency checks — the things QA structurally cannot claim. Every QA report ends with this list.
